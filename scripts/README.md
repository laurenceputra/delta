# Singapore expressway data

`dist/data/roads.json` is an offline extract of OpenStreetMap mainline motorway ways for AYE, BKE, CTE, ECP, KJE, KPE, MCE, PIE, SLE, and TPE. It was generated from [the committed Singapore Overpass export](https://github.com/madeinusmate/fix-singapore-gp/blob/6368d82cd39a16c4e4488c8b7bd1d278e92b80f5/analysis/osm.json) in `madeinusmate/fix-singapore-gp` (commit dated 2026-10-19). The original export does not include an OSM snapshot timestamp. Data: © OpenStreetMap contributors, [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/).

To update, download a current Overpass JSON extract containing all Singapore drivable highway ways, including motorway and motorway_link, with geometry, node IDs and tags, then run:

```sh
python scripts/build-roads.py path/to/osm.json
```

The builder currently pins the source URL and commit in metadata. Update those constants when using a different extract. The output includes per-way coordinates in `[longitude, latitude]` order, mapped `maxspeed` values, and motorway_link destinations at shared source nodes. `nextRoadIds` preserves direct OSM mainline topology. `chains` lists connected directed sequences; a short PIE branch merges into the westbound mainline. A chain's `travelDirection` is its end-to-end compass bearing, while each way's `direction` is local bearing.

The checked-in bundle has 1,657 mainline ways across all ten requested refs, 21 directed chains, and 415 exit attachments, of which 385 have a destination or name. Nine ways have no parseable `maxspeed` tag and retain a null limit. OSM speed tags are community data, not a current legal verification. Exit numbers are absent from this source, so the builder does not infer them. The source does not provide motorway_junction nodes, and ramps without a shared mainline node cannot be attached. The North–South Corridor is omitted because this extract does not establish an operational motorway ref for it.

`dist/data/local-roads.json` holds 74,333 additional drivable OSM ways for road name identification, including motorway ramps. It excludes foot, cycle, path, construction, private, and explicitly prohibited motor routes. Null names and speed limits mean the source lacks those tags. The 1.9 MB `local-roads.json.gz` is the compact offline transfer copy; the plain JSON is 17 MB. Coordinates are rounded to five decimal places and interior points closer than five metres are thinned, so this bundle is for identification rather than lane guidance. It is not an exhaustive legal access inventory because OSM access tagging can be incomplete.

`routeNextRoadIds` extends each mainline way with exact directed cross-expressway transitions. Each entry has a destination `roadId`, ordered `connectorIds`, and combined connector `lengthM`. The top-level `connectors` collection stores original motorway_link geometry in travel order, tagged speed, and destination. Empty `connectorIds` means the two motorway ways share an OSM node directly. Connector searches use at most four directed links and two kilometres, and retain alternative paths; ordinary local roads never bridge a route. This graph supports reconstruction, but an exit ramp path should only be selected when the observed position or heading supports it. The MCE/KPE boundary is a direct shared-node connection in both travel directions (MCE way 253945383 to KPE way 633601611; KPE way 546398066 to MCE way 116796554).

The `entries` collection has 219 mapped on-ramp/mainline attachments. Each is an exact shared OSM node where a directed motorway_link ends on a mainline way, with the ramp and mainline way IDs, coordinate, and geometry-derived bearings. `headingGateDeg` is an application matching heuristic, not a source tag or legal direction rule. The Upper Cross Street approach to CTE follows link ways 480919517 → 480919516 → 121882988, then joins CTE mainline way 174552486 at OSM node 158094620 ([103.8421353, 1.2895016]). An unmapped or disconnected ramp has no entry record.

`rampGraph` contains directed endpoint topology for 1,966 motorway_link edges, including a reverse edge for one explicitly two-way link. Its `links` carry exact start/end OSM node IDs, endpoint coordinates, next link IDs, and adjacent mainline/local road IDs. Local adjacency requires a directed local way to end at the ramp start or start at the ramp end; `oneway=-1` geometry and node order are reversed together. Geometry stays in `connectors` and `local-roads.json` keyed by the same way ID; the reverse edge has a `-reverse` suffix. Its `paths` classify 441 local-to-mainline joins, 499 mainline-to-local leaves, and 154 mainline-to-mainline transfers (including same-ref paths). Searches stop at a mapped mainline attachment and are bounded to 5 km/64 links with cycle guards. No searches hit those bounds in the pinned extract; 62 traversals ended without a mapped mainline, local continuation, or next ramp and remain unresolved. Multiple paths remain alternatives; map connectivity alone does not establish the vehicle's actual route. A real TPE leave is way 756847962 → ramp 139718132 → local way 628738331. A real ECP-to-KPE transfer is ECP way 670121242 → ramps 32605139, 140562826, 528189241 → KPE way 633601611. No direct KPE-to-CTE ramp-only transfer was found within these bounds.
